# WIBWOBWIKI

*The gazetteer of Wibwobworld.* A paper the world prints about itself: every being, place,
thing and event on the record, a map, a changes bulletin, the strip, and a door for tales.

Live: https://wiki.wibandwob.com

- `site/` is the published site. It is regenerated from the world's record and pushed here
  on a timer; do not edit it by hand.
- `lore/` is hand-written. `tales/` is the fandom's. See `CONTRIBUTING.md`.
